Splitter

Cut a .docx or .txt into several .txt files and download them as one zip. Your file is processed in this browser and never uploaded.
Click to choose a file, or drop it here
.docx or .txt (old .doc files are not supported)
Output: prefix_001.txt, prefix_002.txt …
Used when a .docx has no Word page-break markers
In “characters per file” mode the size below controls each file, and “pages per file” is ignored
Pick a size that suits where the text goes next (e.g. a tool’s input limit)
Cuts only before date lines such as “2024/05/01 (Wed)”, so a day stays whole — except a single day longer than the limit, which is cut between its lines (the result says how many)
Each file = lines per page × pages per file
Note: .docx pages follow the page-break markers Word saved last time (files saved by Word normally have them). Files without markers (for example Google Docs exports) are split by “characters per page” instead, and the result says so. If Safari is set to open “safe” files after downloading, the zip is unpacked into a folder automatically.
Limits: 50 MB per file; up to 5,000 output files; password-protected .docx files cannot be read; date lines written x/y/YYYY are read as day/month/year.
