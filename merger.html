Merger

File several .txt files by the date lines inside them: a folder per year, a file per month. A file that spans two months is split between them correctly. Your files are processed in this browser and never uploaded.
Click to choose, or drop several .txt or .zip files
Choose all the parts at once, or one .zip containing them — processed in file-name order
Date lines such as 30/12/2024 (Mon), 2024/12/30 and 2024年12月30日 are recognised; x/y/YYYY is always read as day/month/year. Text before the first date line (such as the export header) goes to “undated.txt”.
Limits: 50 MB per .txt (or per file inside a zip), 100 MB per zip, 200 MB per run after unzipping; encrypted zips and ZIP64 are not supported.
